# brgr v2.12.15

Hotfix: bounded evidence reads during worktree reclamation.

## Fix

- v2.12.4 compares each `--evidence-file` with its sealed copy before
  reclaiming a worktree. It read the file whole whatever its size, so a
  multi-gigabyte file left in the worktree was loaded into memory on the
  decision. It now reads at most the task's artifact limit: sealing refuses
  anything larger, so a larger file cannot match and keeps the worktree. The
  check also uses brgr's shared digest function instead of a fourth copy of
  it.

## Upgrading

Install v2.12.15.

```sh
herdr plugin install justn-hyeok/brgr --ref v2.12.15
```

The CLI archive remains unsigned and not notarized.
