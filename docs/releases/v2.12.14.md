# brgr v2.12.14

Hotfix: decisions no longer read every repository brgr knows.

## Fix

- Reclaiming one decided worktree loaded the worktree list of every
  repository brgr had ever recorded, one `git worktree list` each, on every
  `accept`, `reject` and `--ack`. It now reads only the repository that
  worktree belongs to, from the worktree itself. `brgr prune`, which sweeps
  everything, still reads them all.

## Upgrading

Install v2.12.14.

```sh
herdr plugin install justn-hyeok/brgr --ref v2.12.14
```

The CLI archive remains unsigned and not notarized.
