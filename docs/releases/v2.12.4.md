# brgr v2.12.4

Hotfix for v2.12.0's worktree reclamation, which could delete an edited
evidence file.

## Fix

- A task's `--evidence-file` paths are sealed as their own artifacts and left
  out of its `--capture-diff` patch. v2.12.0 removed a worktree once its patch
  still matched the sealed diff, so an evidence file edited after sealing was
  deleted with it. Each evidence file must now still have the digest of an
  artifact sealed with the result; one that changed keeps the worktree, and
  one that is gone has nothing to lose.

## Upgrading

Install v2.12.4.

```sh
herdr plugin install justn-hyeok/brgr --ref v2.12.4
```

The CLI archive remains unsigned and not notarized.
