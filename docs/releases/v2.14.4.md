# brgr v2.14.4

Pane-or-headless auto mode, force-cancel from another session, worker pane
names, Cursor owner notices, and a Claude Code status mod.

## `brgr run --mode auto`

Inside a Herdr pane the run opens a worker pane; without Herdr it is headless.
The receipt says which it picked. `--headless` and pane mode remain explicit.

## `brgr cancel TASK --force`

A later session can stop a worker whose owner is a different bound session
(usage limit, abandoned Claude, Cursor taking over the keyboard). Reaching
`$BRGR_HOME` is the access check. `--force` does not accept or reject a sealed
result. On an already-terminal task it only closes a leftover pane brgr
recorded as its own.

Without `--force`, a stale session after a head handoff still cannot cancel.

## Worker pane names

`[herdr].pane_name_template` names the worker pane (default
`{harness}/{provider}/{model}: {objective}`). Herdr overwrites the label with
`cmd` when the agent registers; brgr applies the template again for a short
window after start. An empty template leaves naming off.

## Cursor owners

A Cursor Herdr pane is a `cursor:<conversation-id>` owner and gets `FROM BRGR`.
Codex and Claude Code paths are unchanged. A Herdr agent kind that is not
`codex`, `claude`, or `cursor` is told that `FROM BRGR` will not arrive; use
`brgr watch`.

## Claude Code mod

`mods/brgr` adds a status line, question and result toasts, `/brgr`, and
`brgr_run` (always `--mode auto`). It never accepts, rejects, applies, revises,
or acknowledges. Types used for `tsc` are stubs in `mods/types/`, not a
machine-local Claude Code bundle path.

## Versioning

Minors are only for Head Migration, Dynamic Workflows, and Unified Continuity
when each actually ships. This release is a patch.

## Upgrade

```sh
cargo install --locked brgr-cli --version 2.14.4
brgr integrate claude install
herdr plugin install justn-hyeok/brgr --ref v2.14.4
```

`brgr integrate` refreshes the installed skill so it mentions `--force` and
Cursor owners. No store migration. The macOS archive remains unsigned and not
notarized.
