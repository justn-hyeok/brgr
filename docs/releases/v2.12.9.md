# brgr v2.12.9

Hotfix: reclaim the worktree when the pane closed on its own.

## Fix

- After a decision, brgr closes the worker's pane and reclaims its worktree.
  If the pane was still busy at the decision and closed later (by the user or
  the agent exiting), the next cleanup found it already gone, marked it
  closed and archived the report, but did not reclaim the worktree, and every
  later cleanup took the already-closed path. The pane-already-gone path now
  reclaims too.

## Upgrading

Install v2.12.9.

```sh
herdr plugin install justn-hyeok/brgr --ref v2.12.9
```
