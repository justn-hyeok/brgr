# brgr v2.10.1

This release publishes the binaries that v2.10.0 did not, and fixes one way a
native worker lost its task. Read the [v2.10.0 notes](v2.10.0.md) for the rest.

## Fixes

- A GJC worker lost its task before it started: Herdr recognized the agent in
  the pane but refused to prompt it ("not an active named agent"), because it
  only prompts agents it started and named. brgr now types the prompt into the
  pane when Herdr refuses that way; Herdr refuses before sending anything, so
  the prompt is never delivered twice.

- The release workflow's smoke test ran `brgr run` without `--headless` on a CI
  machine that has no Herdr pane. Since v2.10.0 the default is the harness's
  native TUI in a Herdr pane, so the run stopped with "default TUI execution
  needs an exact Herdr source" and no release was created. The smoke test now
  asks for a headless run explicitly.

## Upgrading

Install v2.10.1, then run `brgr integrate codex install`.

```sh
herdr plugin install justn-hyeok/brgr --ref v2.10.1
```

The CLI archive remains unsigned and not notarized.
