# brgr v2.10.2

This release rewrites the brgr skill and installs it for Claude Code too.

## Skill

The skill now opens with the rules brgr runs by:

- Every worker opens as a Herdr pane beside the caller, running the harness's
  own TUI: to the right of a wide pane, below a narrow one, or in a tab.
  `--headless` is not for normal use.
- Work meant for Claude uses `local.claude-code`.
- Workers always run with full permissions; `--permission` is ignored.
- Every result is decided (`accept`, `reject`, or `result TASK --ack`) so brgr
  closes the worker's pane; `--keep-pane` only when the user asks.

It also corrects two wrong statements. The skill no longer lists permission as
something to carry over, and it no longer says brgr runs without a pane when it
cannot find the caller: since v2.10.0 it waits for the calling Codex pane and
fails if it cannot find it. New sections cover the run–wait–read–decide–apply
loop, what to do with each notice type, and how to handle common failures
(credits or HTTP errors, an unanswered screen, a missing report, a harness that
needs re-registering after an update). A test now parses every `brgr` command
the skill shows, so the skill cannot drift from the CLI again.

## Claude Code

`brgr integrate claude install|status|uninstall` installs the same skill to
`$CLAUDE_CONFIG_DIR/skills/brgr/SKILL.md` (default `~/.claude`). Like the Codex
install, it records what it wrote and refuses to overwrite a skill you edited.
Claude Code needs no hooks: its sessions already receive notices in their pane.

## Upgrading

Install v2.10.2, then run `brgr integrate codex install` and
`brgr integrate claude install`.

```sh
herdr plugin install justn-hyeok/brgr --ref v2.10.2
```

The CLI archive remains unsigned and not notarized.
