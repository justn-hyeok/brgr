# brgr v2.6.0

This minor release lets a worker run in a Herdr pane where you can watch it,
and makes the sealed diff trustworthy enough to review and integrate from.

## Pane mode

- Inside Herdr, Claude Code now runs as its own interactive session in a pane
  split beside yours, without taking focus. brgr starts it with the task's
  permission, model, and effort flags, sends the prompt, seals the report the
  agent writes, and closes the pane when the task ends. That includes a failed
  run.
- If the agent stops at an approval or question prompt, the owner gets a
  question notice naming the pane. brgr never answers the prompt.
- Claude Code trusts a folder by its git repository. For a brgr worktree, that
  is the source checkout: running in a repository you already trust needs no
  new answer, and a repository you have never opened in Claude Code asks once.
- `read-only` tasks, runs outside Herdr, and harnesses without the new
  `launch.interactive` manifest field keep the headless run.
  `brgr config set-pane-mode false` turns pane mode off.

## Reviewing and integrating a worker's change

- A sealed diff now includes files the worker created without staging them.
  Before, those files dropped out of the patch silently, and `brgr apply`
  integrated an incomplete change. Ignored files and `--evidence-file` paths
  stay out of the patch.
- `brgr diff TASK` prints the sealed patch, and `--stat` lists its files with
  line counts. They show the same bytes `brgr apply` writes.
- `brgr apply` accepts a target whose `HEAD` has moved on from the task's base
  commit, as long as it descends from it and the patch still applies cleanly.

## Models

- Claude Code and Cline accept `brgr run --model`. Each CLI rejects an unknown
  name itself, before any request.

## Skills

- The installed Codex skill covers harnesses, permission levels, model
  selection, pane mode, `brgr diff`, apply, and prune. Run
  `brgr integrate codex install` to update it.
- A new `brgr-diff-review` skill in `skills/` covers the diff flow from request
  to integration.

## Upgrading

Manifests registered by v2.6.0 can carry `launch.interactive`, which older
versions cannot read. Install v2.6.0, then re-register Claude Code
(`brgr harness add`) to enable pane mode for it.

The known limits of v2.4.0 still apply; see the
[readiness checklist](../readiness/v1-readiness-checklist-2026-09-14.md).

Install the Herdr plugin on Apple Silicon macOS 15 or newer:

```sh
herdr plugin install justn-hyeok/brgr --ref v2.6.0
```

The CLI archive remains unsigned and not notarized.
