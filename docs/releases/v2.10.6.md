# brgr v2.10.6

Every brgr command now checks the worker column beside each caller and evens
it out.

## Layout

- v2.10.5 evened out a caller's workers only when brgr itself opened or closed
  one. A pane closed by hand, a dragged border, or a resized terminal left the
  column uneven until the next worker came or went. Now every brgr command
  (`status`, `wait`, `result`, `accept` and the rest) runs the same check after
  it finishes. Callers with no open workers cost only a read of the pane
  receipts, with no Herdr call.
- As before, only panes brgr opened for that caller are resized.

Seen live: two workers at 30 and 29 rows were dragged to 47 and 12, and one
`brgr status` put them back to 30 and 29.

## Upgrading

Install v2.10.6.

```sh
herdr plugin install justn-hyeok/brgr --ref v2.10.6
```

The CLI archive remains unsigned and not notarized.
