# brgr v2.12.10

Hotfix: stop reassessing kept worktrees on every hook.

## Fix

- The pending-work pass that runs on every Codex hook (and every few ticks of
  a pane session) calls pane cleanup for each closed pane, and each call
  reassessed a worktree the decision had kept: a `git status`, perhaps a diff,
  and the same "kept worktree" note on stderr, again and again, growing with
  every kept worktree. Each revision is now assessed once, recorded as
  `runs/<task>-r<n>.reclaimed`. A worktree kept then stays until
  `brgr prune --apply`.

## Upgrading

Install v2.12.10.

```sh
herdr plugin install justn-hyeok/brgr --ref v2.12.10
```
