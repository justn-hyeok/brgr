# brgr v2.9.3

This patch release makes brgr safe to call from Codex under Herdr.

## Fixes

- brgr now trusts `HERDR_PANE_ID` only when it provably runs inside that pane.
  Codex runs shell commands and hooks in a shared background daemon that keeps
  another pane's Herdr environment.
  - From Codex, pane mode split beside a closed pane and lost the task.
  - A hook could bind the Codex session to another Codex's pane, so completion
    notices went to the wrong conversation.

  Such callers now run headless, get no worker pane, and register no
  notification surface. `local.omp-herdr` refuses them.
- Pane mode no longer sends its prompt into a menu. Herdr reported Codex ready
  while it showed an update offer, and the prompt's Enter would have chosen
  "Update now". The run now asks its owner and waits for the menu to go.

## Upgrading

Install v2.9.3, then run `brgr integrate codex install`.

The known limits of v2.4.0 still apply; see the
[readiness checklist](../readiness/v1-readiness-checklist-2026-09-14.md).

Install the Herdr plugin on Apple Silicon macOS 15 or newer:

```sh
herdr plugin install justn-hyeok/brgr --ref v2.9.3
```

The CLI archive remains unsigned and not notarized.
