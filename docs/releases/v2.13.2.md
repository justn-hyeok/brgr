# brgr v2.13.2

OpenCode 2 registers again.

## Fix

- OpenCode 2.0 removed `opencode run --variant`; a variant is now written into
  the model name (`--model provider/model#variant`). brgr's OpenCode recipe
  required `--variant`, so after Homebrew upgraded OpenCode, `brgr harness add`
  failed ("help does not document a supported bounded fresh-run flag
  contract") and the registered harness went unspawnable. `--variant` is now
  required only for effort selection: on OpenCode 2 the harness registers and
  reports effort as unsupported; pass a variant in the model name instead.
  Checked live with OpenCode 2.0.20: registered, a pane task reported, was
  accepted, and its worktree was reclaimed.

## Upgrading

Install v2.13.2 and register OpenCode again at its current path:

```sh
herdr plugin install justn-hyeok/brgr --ref v2.13.2
brgr harness add "$(command -v opencode)" --workspace ~/brgr-scratch --prompt "Reply with OK"
```

The CLI archive remains unsigned and not notarized.
