# brgr v2.15.7

A head is handed to another harness on plan usage only. A full context window is no
longer a handoff condition: it was added in 2.15.5 without being asked for, and
compaction or a fresh session is the answer to it, not a different harness.

## What changes

- `brgr config set-handoff-condition` no longer takes `--context-percent`, and
  `--quota-percent` is required. A script that passes `--context-percent` now fails.
- A config written by 2.15.5 or 2.15.6 that names `context_percent` still loads. The
  value is ignored and is not written back.
- Cursor Agent reports no plan figure, so a Cursor head is never told to hand off.
  Its usage recorder (`brgr integrate cursor install`) still works but has nothing
  to act on; `uninstall` removes it.

## Checked

`cargo fmt`, `clippy -D warnings` and `cargo test --workspace --all-features` pass.
Not checked in a live Herdr pane.

No store migration.
