# brgr v2.11.0

One release for the fixes from an outside review of v2.10.6.

## Fixes

- **An agent Herdr never classifies got no unknown-screen deadline.** GJC and
  Command Code report `unknown`, and brgr only read the screen when Herdr said
  `blocked`, so a dialog in front of them waited out the task deadline (an
  hour) instead of failing after three minutes. Now a screen that stays exactly
  the same for ten polls is read like a blocked one. A rule's dialog is
  answered; any other dialog is reported to the owner, starts the
  three-minute deadline, and is never pressed.
- **The update-offer rule skipped an agent's own questions.** Any menu with
  "update" or "upgrade" and a "Later"/"Skip" option was answered "Later", such as
  "Update the schema now? 1. Yes 2. Later". The rule now also needs an offer's
  wording ("available", "new version") or a version number.
- **A Claude Code owner's notices could reach a different Claude Code.** Herdr
  keeps no session id for Claude Code, so brgr checked only the pane and the
  agent kind. brgr now records the Claude Code process that registered the
  owner, and a notice goes to that pane only while that process still runs
  there.
- **Finding the calling Codex pane needed one exact line shape.** It matched
  only `Ran brgr ...`. It now also accepts brgr run by path, as `$BRGR_BIN`,
  after `cd DIR &&`, or after `NAME=value`, and still rejects brgr appearing
  only as an argument. `brgr doctor` reports the installed Codex under
  `codex_trace` and whether it is the release these lines were checked against.
- **A finished task's notification dispatcher scanned every Codex pane before
  exiting.** It now exits at once when the run is over and nothing is left to
  send. This made a contract test fail under load.
- **`brgr doctor` required the Codex integration**, so a Claude Code-only setup
  never reported `ok`. Either integration is now enough; one that is installed
  must be current.
- **Platform defaults:** the OMP Herdr adapter runs `python3` (macOS ships no
  `python`). Outside macOS the default control home is `$XDG_DATA_HOME/brgr`
  (or `~/.local/share/brgr`). macOS keeps `~/Library/Application Support/brgr`,
  and a regression test runs a pane task with spaces in the home and workspace
  paths.

## Docs

The README is cut to about 120 lines, with a troubleshooting table. The
detailed contract moved to [docs/guides/reference.md](../guides/reference.md).

## Upgrading

Install v2.11.0, then run `brgr integrate codex install` and
`brgr integrate claude install`.

```sh
herdr plugin install justn-hyeok/brgr --ref v2.11.0
```

The CLI archive remains unsigned and not notarized.
