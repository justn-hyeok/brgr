# brgr v2.13.3

OpenCode 2 workers stop when brgr stops them, and take a model again.

## Fixes

- **A stopped OpenCode 2 run kept working.** OpenCode 2 runs a task in a shared
  background service unless it gets `--standalone`. When a deadline or a
  cancellation stopped the client, the service carried on: with OpenCode 2.0.20,
  a task told to sleep 25 seconds and then write a file still wrote it after
  its `opencode run` client was stopped 12 seconds in. brgr now passes
  `--standalone`, in the pane as well, whenever `opencode run --help`
  documents it. Checked live: a headless brgr run stopped by a 20-second
  deadline did not write the file it had been asked to write after 35 seconds,
  and a pane task ran with `--standalone --auto` and reported. Closing a pane
  mid-task was not checked.
- **`--model` failed on OpenCode 2.** `opencode models` printed 0, 206, 242 or
  251 models from one call to the next, and none with `--standalone`, so brgr's
  model check failed with "model catalog recipe or output is malformed".
  OpenCode refuses an unknown model itself before any request, so brgr now
  leaves the check to it, as it does for Codex, Copilot, Gemini and Pi. This
  also makes `--model provider/model#variant` work, as the v2.13.2 notes said
  it would.
- **A pane task with `--model` could not start on OpenCode 2.** OpenCode 2's TUI
  has no `--model` option (OpenCode 1's has) and exited at once. A pane task that names a model
  now fails before it starts and says to use `--headless`, as one that names an
  effort already did.
- Recipe flags must now appear in the help as whole flags: `--auto` is no
  longer satisfied by a longer flag such as `--autoupdate`.

## Compatibility

A manifest registered by v2.13.3 for OpenCode 2 records `model_print_only`,
which v2.13.2 and older cannot read. Register OpenCode again after a downgrade.

A model stored for OpenCode 2 with `brgr config set model … --harness
local.opencode` now fails `brgr config check` and every pane run on that
harness. Remove it, or pass `--headless`.

## Upgrading

Install v2.13.3 and register OpenCode again, so its manifest gets
`--standalone` and the new model check:

```sh
herdr plugin install justn-hyeok/brgr --ref v2.13.3
brgr harness add "$(command -v opencode)" --workspace ~/brgr-scratch --prompt "Reply with OK"
```

The CLI archive remains unsigned and not notarized.
