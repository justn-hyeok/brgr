# brgr v2.15.1

Cursor's conversation id is the owner session, so a Cursor pane can take an
abandoned head without `--as`.

## Cursor session

v2.15.0 `head claim` from a Cursor Herdr pane failed with `a session is
required` unless the command passed `--as`. Codex still prints `--as` so its
pane can be found; Cursor already has `CURSOR_CONVERSATION_ID`. brgr now
reads that the same way it reads `CLAUDE_CODE_SESSION_ID`. `--as` remains
valid and still wins when set.

The installed skill says so. Run `brgr integrate` to refresh it.

## Upgrade

```sh
cargo install --locked brgr-cli --version 2.15.1
brgr integrate claude install
herdr plugin install justn-hyeok/brgr --ref v2.15.1
```

No store migration. The macOS archive remains unsigned and not notarized.
