# brgr v2.10.5

Workers opened beside one caller now share one evenly divided column.

## Layout

- The first worker splits the caller as before: to the right of a wide caller,
  below one narrower than 100 columns.
- Later workers split the last worker downward instead of the caller again. The
  caller keeps its half however many workers run. Before, every worker halved
  the caller, so it kept shrinking and the workers ended up in uneven sizes.
- After a worker opens or closes, brgr resizes the caller's workers to equal
  heights. A closed pane's space would otherwise all go to its neighbour.
- When another worker would leave fewer than 10 rows each, it opens in a new tab.
- Only panes brgr opened for that caller are resized. Panes you made yourself
  are never touched. When the last worker closes, the caller gets its full width
  back.

Seen live with three Claude Code workers beside a 208-column caller: the caller
kept 104 columns and the workers got 20, 20 and 19 rows. After the middle one
closed, the other two got 30 and 29 rows.

## Upgrading

Install v2.10.5, then run `brgr integrate codex install` and
`brgr integrate claude install` (the skill describes the new layout).

```sh
herdr plugin install justn-hyeok/brgr --ref v2.10.5
```

The CLI archive remains unsigned and not notarized.
