# brgr v2.12.13

Hotfix: the "kept worktree" note gives advice the owner can follow.

## Fix

- When a decision keeps a worktree because of an ignored file, its note
  reused `brgr prune`'s wording, "pass --include-ignored to remove them", a
  flag `accept`, `reject` and `result --ack` do not take. The note now says
  "`brgr prune --apply --include-ignored` removes them" and ends with
  "`brgr prune` lists it". A decision prints it once: the pane cleanup and the
  decision both used to reclaim, which since v2.12.10 assess once.

## Upgrading

Install v2.12.13.

```sh
herdr plugin install justn-hyeok/brgr --ref v2.12.13
```
