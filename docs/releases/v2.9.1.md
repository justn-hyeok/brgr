# brgr v2.9.1

This patch release fixes two pane-mode failures found by running several pane
tasks at once.

## Fixes

- A pane-mode run completes once the agent is idle and its report exists. It
  used to also require having seen the agent working. Herdr may never show
  that, so a finished Cursor task waited out its whole deadline.
- A cancelled or killed pane-mode run no longer leaves its pane open with the
  agent still inside. The supervisor closes the pane the run recorded. A run
  with `--keep-pane` keeps it.

## Upgrading

No manifest or configuration change. Install v2.9.1 over v2.9.0.

The known limits of v2.4.0 still apply; see the
[readiness checklist](../readiness/v1-readiness-checklist-2026-09-14.md).

Install the Herdr plugin on Apple Silicon macOS 15 or newer:

```sh
herdr plugin install justn-hyeok/brgr --ref v2.9.1
```

The CLI archive remains unsigned and not notarized.
