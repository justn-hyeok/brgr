# brgr v2.13.8

Read another session's task, decide and clean up in one command, and a Mac that
sleeps mid-start.

## New

- **`--observe` on `status`, `result` and `diff`.** A task owned by another
  session, for example an orchestrator's, could not be read by a person or a
  second agent without taking it over with `bind`. `--observe` reads it without
  the owner-session check and prints one note on stderr saying it did. It only
  reads: `result --observe --ack` is refused, and `accept`, `reject`, `land`,
  `apply` and `bind` still need the owner's session.
- **`--include-ignored` on `accept`, `reject` and `land`.** A decision already
  removes the worktree it finished, but kept it when only ignored files (build
  output, caches) were left, so each result still needed a separate `prune
  --apply --include-ignored`. The flag removes that worktree with the decision.
  Without it nothing changes. A pane-mode worktree, reclaimed later when its pane
  closes, honours the choice. brgr does not delete ignored files on a timer: it
  cannot know they are disposable, only the owner can.

## Fixes

- **A Mac that slept in the middle of `brgr run` failed with a probe error.** A
  run that started, then lost 17 minutes to sleep, woke with the network down and
  ended with `bounded model catalog probe failed`, after what looked like a
  three-minute wait. On macOS `run` and `revise` now hold an idle-sleep
  assertion (`caffeinate -i -w`, tied to the brgr process) while they start a
  task; a foreground run keeps it for the whole run. A probe that still fails
  says the machine was asleep when the wall clock ran 20 seconds or more ahead
  of the monotonic one, and waits longer before its retry. Closing the lid still
  sleeps the machine.
- **`brgr revise --help` did not say what `--workspace` does.** A revision
  starts from that repository's current HEAD, not from the base of the revision
  it replaces, so work merged in between is part of its base. This already worked
  and now has a test and a help text.

## Upgrading

```sh
herdr plugin install justn-hyeok/brgr --ref v2.13.8
```

Existing commands behave as before.

The CLI archive remains unsigned and not notarized.
