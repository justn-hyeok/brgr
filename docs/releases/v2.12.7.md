# brgr v2.12.7

Hotfix: the rest of the secret-deletion bug v2.12.1 fixed half of.

## Fix

- v2.12.1 made brgr read ignored paths at the level their pattern matched, so
  a lone `dist/.env` is no longer folded into `dist/`. But when `dist/` itself
  matches an ignore pattern (a `.gitignore` with `dist/` is common), git
  reports only `dist/` and never lists what is inside, and v2.12.1 still
  counted `dist/` as regenerable, so a `.env` or a key in it went with the
  worktree. `dist`, `build` and `coverage` are no longer regenerable: people
  keep their own files under such generic names. Only directories a tool owns
  and recreates in full still are: `node_modules`, `target`, `.next`, `.turbo`,
  `__pycache__`, `.pytest_cache`, `.mypy_cache`, `.venv`, `.gradle`.

## Upgrading

Install v2.12.7.

```sh
herdr plugin install justn-hyeok/brgr --ref v2.12.7
```

The CLI archive remains unsigned and not notarized.
