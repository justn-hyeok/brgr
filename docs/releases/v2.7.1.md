# brgr v2.7.1

This patch release stops a busy machine from making a working harness look
broken.

## Fix

- A harness's version, help, and model-catalog probes may now take 15 seconds
  instead of 5. The limit exists only to catch a hung CLI; a healthy one
  answers in about a second. On a busy machine, an ordinary stall of a few
  seconds used to push a working harness past the old limit. `brgr run` then
  refused the task as `timed_out`, or failed a valid `--model` request with a
  catalog-probe error instead of checking the model.
- A genuinely hung CLI is now reported after 15 seconds rather than 5.

## Upgrading

No manifest or configuration change. Install v2.7.1 over v2.7.0.

The known limits of v2.4.0 still apply; see the
[readiness checklist](../readiness/v1-readiness-checklist-2026-09-14.md).

Install the Herdr plugin on Apple Silicon macOS 15 or newer:

```sh
herdr plugin install justn-hyeok/brgr --ref v2.7.1
```

The CLI archive remains unsigned and not notarized.
