# brgr v2.6.1

This patch release stops brgr from recording a task lost while its Herdr
worker pane is still opening.

## Fix

- A task placed in a Herdr worker pane now has a minute, not five seconds, to
  be claimed. Its supervisor exists only once Herdr has opened the pane and
  started `brgr plugin worker` there, and on a busy machine that can take
  longer than five seconds. Until now, any brgr command run in that window,
  such as `brgr status`, recorded the task lost while its worker was still
  starting.
- The launch envelope records what will claim the task (`claimant`). A task
  run by a detached supervisor keeps the five-second window, and so do
  envelopes written by earlier versions.

## Internal

- The largest source files are split into modules by responsibility, with no
  change in behavior: the store, core, runner, and registry crates, and the
  CLI entry point.
- Two timing-sensitive tests no longer fail under a fully parallel test run.

## Upgrading

No manifest or configuration change. Install v2.6.1 over v2.6.0.

The known limits of v2.4.0 still apply; see the
[readiness checklist](../readiness/v1-readiness-checklist-2026-09-14.md).

Install the Herdr plugin on Apple Silicon macOS 15 or newer:

```sh
herdr plugin install justn-hyeok/brgr --ref v2.6.1
```

The CLI archive remains unsigned and not notarized.
