# brgr v2.12.6

Hotfix: reject-then-revise works again for Git tasks.

## Fix

- `brgr revise TASK` without `--workspace` used the previous revision's task
  worktree as its source. That worktree lies under the brgr control home,
  which admission refuses as a source ("brgr control home and the source
  workspace must not overlap"), so revising a Git task failed even before
  v2.12.0. Since v2.12.0 the rejection also removes that worktree. A revision
  of a Git task now starts from the repository recorded when its worktree was
  created; a non-Git task still revises in place. If no repository was
  recorded (tasks from before checkouts were recorded), the error says to pass
  `--workspace`.

## Upgrading

Install v2.12.6.

```sh
herdr plugin install justn-hyeok/brgr --ref v2.12.6
```

The CLI archive remains unsigned and not notarized.
