# brgr v2.12.12

Hotfix: keep options carry over to revisions, and `--keep-pane` stops
mattering for headless worktrees.

## Fixes

- `brgr revise` took `--keep-worktree` and `--keep-pane` from its own command
  line only, while it inherits delegation and calling options from the
  previous revision. A task started with `--keep-worktree` had its revision's
  worktree reclaimed. A revision now keeps what its task was asked to keep;
  passing the flag on `revise` still adds it.
- `--keep-pane` kept a worktree because a kept pane's worker still runs in
  it. A headless run has no pane, so for it `--keep-pane` no longer stops
  reclamation.

## Upgrading

Install v2.12.12.

```sh
herdr plugin install justn-hyeok/brgr --ref v2.12.12
```

The CLI archive remains unsigned and not notarized.
