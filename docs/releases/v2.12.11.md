# brgr v2.12.11

Hotfix: headless decisions reclaim even when the supervisor is still exiting.

## Fix

- A detached headless run seals its result, then its supervisor takes a
  moment to exit. An owner who accepted at once, from the completion notice,
  found the worker still running, so reclamation skipped silently, and a
  headless task has no pane cleanup to try again later: the worktree stayed.
  The decision now waits up to five seconds for the worker to exit, then
  reclaims.
- Reclamation now returns before assessing a revision that is not settled, so
  the once-only marker from v2.12.10 is never written by an assessment that
  ran before the decision.

## Upgrading

Install v2.12.11.

```sh
herdr plugin install justn-hyeok/brgr --ref v2.12.11
```
