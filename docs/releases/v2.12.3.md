# brgr v2.12.3

Hotfix for the code documentation of v2.12.0's worktree reclamation. No
behavior changes.

## Fix

- v2.12.0 inserted `reclaim_task` between `brgr prune`'s doc comment and its
  function, so the new function's documentation began with "Runs `brgr prune`
  and prints its report" and the prune entry point had none. Each comment is
  back on its own function.

## Upgrading

Install v2.12.3.

```sh
herdr plugin install justn-hyeok/brgr --ref v2.12.3
```

The CLI archive remains unsigned and not notarized.
