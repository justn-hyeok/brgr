# brgr v2.9.2

This patch release makes the Codex Stop hook work.

## Fix

- When brgr has unprocessed results, the Codex Stop hook now blocks the stop as
  intended. Its output used to carry a `hookSpecificOutput` object, which Codex
  does not accept for Stop. Codex rejected the output with "invalid stop hook
  JSON output" and let the session stop.

## Upgrading

Install v2.9.2, then run `brgr integrate codex install` so the hooks point at
the new binary.

The known limits of v2.4.0 still apply; see the
[readiness checklist](../readiness/v1-readiness-checklist-2026-09-14.md).

Install the Herdr plugin on Apple Silicon macOS 15 or newer:

```sh
herdr plugin install justn-hyeok/brgr --ref v2.9.2
```

The CLI archive remains unsigned and not notarized.
