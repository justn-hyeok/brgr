# brgr v2.10.3

This release makes the re-certify command that `brgr harness status` prints
work as printed for a harness whose executable is a script.

## Fixes

- After Command Code updated itself, `brgr harness status local.command-code`
  told the user to run `brgr harness add '.../command-code/dist/index.mjs' ...`,
  and that command failed with "help does not document a supported bounded
  fresh-run flag contract". brgr picks a harness's recipe by the executable's
  file name, and `index.mjs` names no recipe. When the file name names no
  recipe, `harness add` and `harness draft` now use the name of the harness
  already registered for the same executable.

## Upgrading

Install v2.10.3.

```sh
herdr plugin install justn-hyeok/brgr --ref v2.10.3
```

The CLI archive remains unsigned and not notarized.
