# brgr v2.12.1

Hotfix for v2.12.0's worktree reclamation, which could delete a secret.

## Fix

- git reports a directory whose files are all ignored as one entry. With a
  `.env` (or `*.env`) pattern, a lone `dist/.env` or `build/prod.env` was
  reported as `dist/` or `build/`, which v2.12.0 counts as a regenerable build
  directory, so the decision that reclaimed the worktree deleted the secret
  with it. brgr now asks git for ignored paths at the level their pattern
  matched (`--ignored=matching`), and only an entry git reports as a directory
  named `node_modules`, `target`, `dist`, `build` and the like is regenerable.
  A file inside one keeps the worktree, as any other ignored file does.

## Upgrading

Install v2.12.1.

```sh
herdr plugin install justn-hyeok/brgr --ref v2.12.1
```

The CLI archive remains unsigned and not notarized.
